# 梯度下降 Gradient Descent 完整详解（基础→数学→变种→优缺点→实操）
## 一、核心思想：下山找最低点
### 1. 直观比喻把损失函数 $L(\theta)$ 想象成一座高低起伏的山地，参数 $\theta$ 是你的坐标，目标走到山谷最低点（损失最小）。
* 梯度 $\nabla L(\theta)$ = 当前位置最陡峭上升的方向；
* 想要下山，就往梯度反方向走；
* 每一步走多远由学习率 $\eta$ 控制。
### 2. 核心迭代公式（梯度下降万能更新式）
$\theta = \theta - \eta \cdot \nabla L(\theta)$
符号解释：
$\theta$：模型所有可学习参数（权重 w、偏置 b）；
$\eta>0$：学习率（learning rate）；
$\nabla L(\theta)$：损失函数对参数的梯度（偏导数向量）；
减号：沿梯度负方向更新，降低损失。
## 二、数学推导：以简单线性回归举例
模型：$\hat{y}=w x + b$
损失 MSE：$L(w,b)=\frac{1}{N}\sum_{i=1}^N \frac12 (\hat{y}_i - y_i)^2$
求梯度（偏导）：
$\frac{\partial L}{\partial w} = \frac1N \sum_{i=1}^N (\hat{y}_i - y_i)x_i
\frac{\partial L}{\partial b} = \frac1N \sum_{i=1}^N (\hat{y}_i - y_i)$
参数更新规则：
$w = w - \eta \cdot \frac{\partial L}{\partial w},\quad b = b - \eta \cdot \frac{\partial L}{\partial b}$
每一轮遍历全部样本、算全部梯度再更新 = 标准批量梯度下降 GD。
## 三、3 大主流梯度下降变体（区别仅在于用多少样本算梯度）
### 1. BGD 批量梯度下降 Batch Gradient Descent
规则：全部 N 个样本一起计算梯度，一次更新参数；
优点：梯度方向稳定、收敛平稳，能精准走向全局极小；损失单调下降；
缺点：
数据集百万 / 千万级时，每轮计算量极大，内存爆炸；
无法在线更新数据（新数据来了要重算全部样本）；
适用：小数据集、离线训练。
### 2. SGD 随机梯度下降 Stochastic Gradient Descent
规则：每次只取 1 个样本算梯度、立刻更新；
$\theta = \theta - \eta \cdot \nabla L_i(\theta)$
优点：
单步计算极快，适合超大样本、在线学习；
梯度噪声自带正则化，容易跳出局部极小；
缺点：
梯度震荡严重，损失上下波动，永远无法精准收敛到最低点；
学习率过大极易发散；
适用：深度学习大数据、在线数据流。
### 3. Mini-BGD 小批量梯度下降 Mini-Batch Gradient Descent（深度学习默认）
规则：每次取一小批样本（batch size，常见 32/64/128/256）计算梯度更新；
折中优势：
梯度比 SGD 平稳，比 BGD 计算快；
充分利用 GPU 矩阵并行加速；
少量噪声帮助逃离局部最优；
行业标准：深度学习框架默认小批量梯度下降。
## 四、关键超参数：学习率 η（最影响收敛成败）
### 1. 学习率过大
步幅太大，直接跨过最低点，损失震荡、甚至发散（Loss 越来越大）；
例：山谷底部来回横跳，永远无法收敛。
### 2. 学习率过小
下山速度极慢，迭代几万轮才能收敛，训练成本爆炸；容易困在平缓高原区域停滞。
### 3. 学习率优化策略（解决固定 η 缺陷）
学习率衰减：训练逐步降低 η，前期大步快速下降，后期精细收敛；
指数衰减、余弦退火、阶梯衰减；
自适应优化器（基于梯度下降改良）：Adam/RMSprop/AdaGrad，自动给不同参数配不同学习率；
稀疏参数大学习率，频繁更新参数小学习率。

## 五、梯度下降的核心痛点与缺陷
### 1. 局部最优陷阱损失函数非凸（深度学习几乎全是非凸），梯度下降只会往就近山谷走，容易卡在局部极小，找不到全局最优；
SGD / 小批量噪声可一定程度缓解，但无法彻底解决。
### 2. 鞍点（Saddle Point）曲面某点梯度 = 0，但既不是谷底也不是山顶；
高维神经网络大量存在鞍点，梯度接近 0，参数几乎不更新，训练停滞。
### 3. 梯度消失 / 梯度爆炸（深度神经网络致命）
梯度消失：多层链式求导后梯度无限趋近 0，浅层权重不更新；
梯度爆炸：梯度数值极大，参数剧烈跳动、损失 NaN；
解决方案：激活函数更换、BN 层、梯度裁剪、残差连接。
### 4. 不同参数梯度尺度差异大
比如权重 w 梯度大、偏置 b 梯度极小，统一 η 会导致更新失衡；
→ Adam 等自适应优化器专门解决该问题。
## 六、梯度下降改良优化器（本质都是 GD 的升级版）
原始 GD 固定学习率、全局统一步长，工程几乎不用；深度学习全部用自适应梯度下降变种：
* AdaGrad：历史梯度平方累加，稀疏特征自动降学习率；适合 NLP 稀疏数据；
* RMSprop：梯度平方滑动平均，解决 AdaGrad 学习率持续衰减过快；
* Adam（最常用）：动量 Momentum + RMSprop 结合，兼顾平滑加速与自适应步长；
    * 动量 Momentum：累积历史梯度，平滑震荡、加速下山；
    * 自适应学习率：每个参数独立调整 η；
* Momentum 动量梯度下降：
$v_t = \beta v_{t-1} + (1-\beta)\nabla L,\quad \theta=\theta-\eta v_t$
叠加历史梯度惯性，减少震荡、加快收敛，类似下山带 “冲劲”。
## 七、完整训练流程（梯度下降标准闭环）
1. 随机初始化模型参数 $\theta$；
2. 设定迭代轮数 epoch、batch size、初始学习率；
3. 循环每一轮 epoch：
    * 打乱数据集，切分小批量；
    * 取一个 batch，前向传播计算预测值与损失；
    * 反向传播链式求导，计算该批次梯度 $\nabla L$；
    * 沿梯度负方向更新全部参数；
4. 停止条件：
    * 损失变化小于阈值（收敛）；
    * 达到最大迭代轮数；
    * 验证集损失连续多轮上升（过拟合，早停 Early Stop）。
## 八、优缺点总结
### 优点
* 适用范围极广：线性回归、逻辑回归、神经网络、所有可微分损失；
* 简单易实现，适配大规模数据，支持 GPU 并行；
* 支持在线 / 流式数据增量训练（SGD/MiniBatch）；
* 适配复杂高维参数场景（百万权重神经网络唯一可行优化方式）。
### 缺点
* 依赖可微损失函数，不可微目标无法使用；
* 容易 陷入局部最优、鞍点停滞；
* 对学习率极其敏感，需要调参或自适应优化器；
* 高维曲面收敛速度不稳定，平缓区域下降极慢。
