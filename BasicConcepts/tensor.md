## 定义

### 标量

标量（Scalar）是只有一个数值的数据，可以理解为 **0 维数据** 或 **0 阶张量**。

标量只有大小，没有方向，也没有多个维度结构。

**数学表示**：

```text
x = 3.14
loss = 0.25
learning_rate = 0.001
```

**特点**：

- 只包含一个数值
- 没有长度、行列或更高维结构
- 是向量、矩阵、张量中最基础的数据单位

**AI 中的常见例子**：

- 模型训练中的损失值 `loss`
- 学习率 `learning_rate`
- 一个神经元的权重值
- 一个分类结果的概率值

### 向量

向量（Vector）是一组按顺序排列的数值，可以理解为 **1 维数据** 或 **1 阶张量**。

向量通常用于表示一个对象的多个特征，或者表示文本、图片、用户等对象的语义特征。

**数学表示**：

```text
v = [1, 2, 3]
```

这个向量的形状可以表示为：

```text
shape = [3]
```

表示它包含 3 个元素。

**特点**：

- 由多个标量按顺序组成
- 有长度，也可以表示方向
- 是机器学习中特征表示的基础形式

**AI 中的常见例子**：

- 一个样本的特征向量：`[年龄, 身高, 体重]`
- 词向量 Word Embedding
- 文本向量 Sentence Embedding
- RAG 中用于语义检索的向量表示

### 矩阵

矩阵（Matrix）是由数字按行和列排列形成的二维结构，可以理解为 **2 维数据** 或 **2 阶张量**。

矩阵可以看作多个向量按行或按列组合而成。

**数学表示**：

```text
A = [[1, 2, 3],
     [4, 5, 6]]
```

这个矩阵有 2 行、3 列，形状为：

```text
shape = [2, 3]
```

**特点**：

- 由多个标量按照行和列组成
- 可以表示二维数据结构
- 是线性代数和神经网络计算中的核心结构

**AI 中的常见例子**：

- 神经网络中的权重矩阵
- 一个 batch 的样本特征表
- 图像中的灰度像素矩阵
- Transformer 中的 Query、Key、Value 矩阵

### 张量

张量（Tensor）是标量、向量、矩阵的高维推广，可以理解为 **任意维度的数值数组**。

在深度学习中，张量是最核心的数据结构。PyTorch、TensorFlow 等框架中的数据通常都以张量形式进行存储和计算。

**阶数关系**：

| 数据结构 | 阶数 | 示例形状 | 含义 |
| --- | --- | --- | --- |
| 标量 | 0 阶张量 | `[]` | 单个数值 |
| 向量 | 1 阶张量 | `[3]` | 一维数组 |
| 矩阵 | 2 阶张量 | `[2, 3]` | 二维数组 |
| 高维张量 | 3 阶及以上 | `[2, 3, 4]` | 多维数组 |

**常见张量形状**：

```text
图像数据：[batch_size, channels, height, width]
文本数据：[batch_size, sequence_length, embedding_dim]
视频数据：[batch_size, frames, channels, height, width]
```

**AI 中的常见例子**：

- 图像模型输入张量
- 文本 Embedding 张量
- 神经网络中间层激活值
- 模型参数和梯度

**简单理解**：

```text
标量：一个数
向量：一排数
矩阵：一张表
张量：更高维的数据容器
```
